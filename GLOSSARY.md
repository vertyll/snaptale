# Glossary

Terms the documentation uses, the standard each one comes from, and where it is explained.

| Term                       | Meaning                                                                                                        | Standard                                                                                 | Explained in                                                                                                                    |
|----------------------------|----------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| Access token               | Short-lived JWT (five minutes) that authorizes one API request.                                                | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-1.4) §1.4                      | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| Audience (`aud`)           | The token claim naming who the token is for; a token for another audience is refused.                          | [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519#section-4.1.3) §4.1.3                  | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| Authorization code flow    | Sign-in by redirecting to Keycloak and exchanging the returned code for tokens on the server.                  | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.1) §4.1                      | [Authentication: Signing in](docs/authentication.md#signing-in)                                                                 |
| BFF (backend for frontend) | The server signs the user in and keeps the tokens; the browser holds only a session cookie.                    | —                                                                                        | [Authentication](docs/authentication.md)                                                                                        |
| CSRF token                 | A token from the `XSRF-TOKEN` cookie that every unsafe request repeats in `X-XSRF-TOKEN`.                      | —                                                                                        | [Authentication: CSRF](docs/authentication.md#csrf)                                                                             |
| End-session endpoint       | Keycloak's logout address the browser is sent to, which ends the Keycloak session.                             | [OIDC RP-Initiated Logout](https://openid.net/specs/openid-connect-rpinitiated-1_0.html) | [Authentication: Signing out](docs/authentication.md#signing-out)                                                               |
| ICU MessageFormat          | The message syntax of the catalog, with plural rules for Polish.                                               | [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/)  | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)                                           |
| ID token                   | Token describing who signed in, issued with the access token.                                                  | [OpenID Connect Core 1.0](https://openid.net/specs/openid-connect-core-1_0.html)         | [Authentication: Signing in](docs/authentication.md#signing-in)                                                                 |
| JWKS                       | Keycloak's published public keys, used to verify a token's signature.                                          | [RFC 7517](https://www.rfc-editor.org/rfc/rfc7517)                                       | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| JWT                        | Signed JSON token; the access token is one.                                                                    | [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519)                                       | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| Keycloak realm             | The Keycloak tenant that holds this application's users, roles and clients.                                    | —                                                                                        | [Authentication](docs/authentication.md)                                                                                        |
| Media directory            | Where videos and avatars are stored and served from `/media`.                                                  | —                                                                                        | [SnapTale — back-end: Media](backend/README.md#media)                                                                           |
| Message key                | A key of the message catalog sent instead of prose; the client renders it in the reader's language.            | —                                                                                        | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)                                           |
| PKCE                       | A one-time secret that ties the returned code to the browser that started the sign-in.                         | [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636)                                       | [Authentication: Signing in](docs/authentication.md#signing-in)                                                                 |
| Problem document           | The JSON body of every refusal: status, a message key and its arguments.                                       | [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)                                       | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)                                           |
| Refresh token              | Long-lived token the server trades for a new access token; Keycloak rotates it on every use.                   | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-1.5) §1.5                      | [Authentication: Sessions and refreshing](docs/authentication.md#sessions-and-refreshing)                                       |
| Refresh token rotation     | Every refresh returns a new refresh token and invalidates the old one; replaying a spent one ends the session. | —                                                                                        | [Authentication: Sessions and refreshing](docs/authentication.md#sessions-and-refreshing)                                       |
| Resource server            | How the back-end verifies a token: signature, issuer, expiry, audience.                                        | [RFC 6750](https://www.rfc-editor.org/rfc/rfc6750)                                       | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| `SameSite` cookie          | Cookie attribute that keeps the session cookie off cross-site requests.                                        | [RFC 6265bis](https://datatracker.ietf.org/doc/draft-ietf-httpbis-rfc6265bis/) (draft)   | [Authentication: Every API request is authorized by a token](docs/authentication.md#every-api-request-is-authorized-by-a-token) |
| Sign-out                   | Ends the local session and the Keycloak session.                                                               | —                                                                                        | [Authentication: Signing out](docs/authentication.md#signing-out)                                                               |
| Single-flight refresh      | One refresh per refresh token, shared by every request of the session that needs it at once.                   | —                                                                                        | [Authentication: Sessions and refreshing](docs/authentication.md#sessions-and-refreshing)                                       |
